# Frontend — HRScreeningHelper 🎙️💻

Система разделена на **3 независимых веб-приложения (сайта)** на базе **Streamlit**:

---

## 🌐 Сайты и порты системы

| Порт | Сайт / Контур | Описание |
| :---: | :--- | :--- |
| **8501** | **👤 Портал Кандидата + Демо** | Вход по токену, голосовое приветствие, согласие 152-ФЗ, прохождение вопросов с аудио-озвучкой и записью ответов. Включает вкладку *Демо-генератора* для создания тестовых токенов. |
| **8502** | **🧑‍💼 Кабинет HR-специалиста** | Просмотр транскрипций диалогов соискателей в режиме **слепого независимого оценивания** (оценка ИИ скрыта), выставление балла и характеристики, отправка отчёта для ЛПР. |
| **8503** | **👔 Кабинет ЛПР (Руководителя)** | Финальное согласование кандидатов: сопоставление оценок ИИ и HR, скачивание сформированного Word-отчёта (`.docx`), вынесение резолюции (*Пригласить на 2-й этап* / *Отказ*) и архив решений. |

---

## 🚀 Запуск системы

### Вариант 1: Через Docker Compose (все 3 сайта сразу)
```bash
docker compose up --build -d
```
Docker автоматически запустит:
* `hrscreening_frontend_candidate` на порту `8501`
* `hrscreening_frontend_hr` на порту `8502`
* `hrscreening_frontend_lpr` на порту `8503`

### Вариант 2: Локальный запуск на Windows (без Docker)
В папке `services/frontend/` подготовлены удобные `.bat` скрипты:
* **`run_all_frontends.bat`** — запускает сразу все 3 сайта в трёх отдельных окнах консоли.
* **`run_candidate.bat`** — запускает только портал кандидата (порт 8501).
* **`run_hr.bat`** — запускает только кабинет HR (порт 8502).
* **`run_lpr.bat`** — запускает только кабинет ЛПР (порт 8503).
